# ToDoVQ

ToDoVQ is a React Native productivity app built with Expo and TypeScript. The initial foundation includes navigation for Inbox, Today, Eisenhower Matrix, and Settings, plus service boundaries for local data, calendar integration, NLP, and geofencing.

## Getting started

```bash
npm install
npm start
```

Run quality checks locally with:

```bash
npm run ci
```

The project plan is tracked in [`.github/workflows/todovq_master_plan.md`](.github/workflows/todovq_master_plan.md).
